# Zoonze App

Production-grade **Flutter** app — a bilingual (English/LTR + Arabic/RTL) headless
storefront client for the Zoonze **Magento Open Source 2.4.8-p5** backend (UAE, AED).

**Status:** Phase 0 — foundation in progress. The full spec, architecture, and
phased roadmap land in `CLAUDE.md` during the Phase 0 app build.
